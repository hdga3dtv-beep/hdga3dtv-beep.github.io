# Página de descarga del Planeador

La página está publicada en **https://hdga3dtv-beep.github.io/**. Detecta si la computadora es Windows o Mac y ofrece
la descarga que le toca. Si se abre en un celular, avisa que es para computadora y deja copiar o compartir el enlace.

- `index.html`: la página entera (estilos y código adentro, sin nada de fuera).
- `img/`: la captura del panel y la primera hoja del PDF de la planeación de ejemplo (datos ficticios),
  `vista-previa.jpg` (la imagen que sale al compartir el enlace) y el ícono.
- `fonts/`: las letras del Planeador (Atkinson Hyperlegible, Baloo 2 y Patrick Hand, de Google Fonts, licencia OFL).

Las descargas vienen de los otros dos repositorios:

- Windows: [planeador](https://github.com/hdga3dtv-beep/planeador) → `raw/main/Planeador.zip`
- Mac: [planeador-mac](https://github.com/hdga3dtv-beep/planeador-mac) → `releases/latest/download/Planeador-Mac.zip`

Para probar cómo se ve en otro sistema: `?so=win`, `?so=mac`, `?so=cel` u `?so=otro` al final de la dirección.
